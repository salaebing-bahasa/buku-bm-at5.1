Apakah ayat penyata?ประโยคบอกเล่าคืออะไร

Ayat penyata ialah ayat yang memberikan maklumat atau menceritakan sesuatu, dan diakhiri dengan noktah ( . ).Ayat penyata คือประโยคที่บอกข้อมูลหรือเล่าเรื่อง ลงท้ายด้วยมหัพภาค ( . )

Contohตัวอย่าง

Saya pergi ke sekolah.

Pasar itu dibuka pada waktu pagi.

Kami solat berjemaah di surau.

SubjekประธานPredikatภาคแสดง
Sayapergi ke sekolah.
Ibumembeli sayur di pasar.
Pantai itusangat cantik.

Latihanแบบฝึกหัด

  1. Susun perkataan menjadi ayat penyata.เรียงคำให้เป็นประโยคบอกเล่า

    1. sekolah / ke / pergi / saya →
    2. di / ayah / bekerja / kebun →
    Lihat jawapanดูเฉลย

    Saya pergi ke sekolah. / Ayah bekerja di kebun.

  2. Pisahkan subjek dan predikat.แยกประธานและภาคแสดง

    1. Adik saya membaca buku.
    2. Kampung saya bersih.
    Lihat jawapanดูเฉลย

    Adik saya | membaca buku. / Kampung saya | bersih.

  3. Tulis 3 ayat penyata tentang keluarga kamu.เขียนประโยคบอกเล่าเกี่ยวกับครอบครัว 3 ประโยค

Nilai Murniข้อคิด

Ayat penyata yang baik mestilah benar. Seorang Muslim sentiasa bercakap benar.

ประโยคบอกเล่าที่ดีต้องเป็นความจริง มุสลิมพูดแต่ความจริงเสมอ
